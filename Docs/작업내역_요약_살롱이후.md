## 11/23 — 마을 레벨, 메인메뉴 연출, 2차 최적화
- **방침**: 그동안 남은 일·나중에 할 일은 팀원이 맡기로 함.
- **살롱 주변 서부 마을**: Blender로 로우폴리 에셋을 만들어 `/Game/Asset/Town`에 넣고(원본 `SourceArt/Town/Town.blend`) 살롱 주변에 배치.
  - 앞길: 큰길과 옆길(바퀴 자국), 간판 건물 8종(GENERAL STORE, BANK, HOTEL, SHERIFF, BARBER, BLACKSMITH, POST OFFICE, ASSAY OFFICE)과 집·헛간, 말뚝·가로등·포장마차·통·상자·선인장, 멀리 메사(붉은 바위산).
  - 살롱 뒤: 뒷마당(장작더미·변소·우물·빨랫줄·건초·말 우리·풍차·물탱크), 광산(ORE MINE 갱도·레일·광석 수레·광석 더미·하역대·광산길, 광석 색은 카드 종류에 맞춤), 광부 텐트촌(텐트·모닥불), 묘지.
- **메인메뉴 화면**: 메인메뉴 레벨에도 같은 마을과 해를 넣고, 메뉴 카메라를 길 한가운데서 살롱 정면을 보는 구도로 바꿈.
- **메인메뉴 인트로 연출**: 게임 실행 시 메뉴가 뜨기 전 6.5초 시네마틱(`LS_MenuIntro`).
  - 카메라가 마을 상공에서 곡선을 그리며 내려와 살롱 정면 구도로 도착함.
  - 그동안 해가 한낮에서 `Lvl_Table`과 같은 노을 각도까지 내려감.
  - 메뉴 레벨의 하늘·안개가 점점 노을빛으로 물듦.
  - 끝나면 메뉴 버튼이 뜸(`BP_PC_Menu`에 Delay 6.5초).
- **저사양 최적화 2차(두 레벨 모두)**:
  - 마을 메시 227개 → 구역별 5개로 합침(드로우콜 약 1/15). 원래 배치는 `Saved/town_layout_*.json`에 백업.
  - 그림자 드리우는 포인트 라이트 12개 → 1개(샹들리에), 해 그림자 4단계·200m → 3단계·80m.
  - 스카이라이트 실시간 캡처 끔, 볼류메트릭 구름 샘플 절반.
  - 안티에일리어싱 TSR → TAA, 모션블러·화면 반사 끔(`DefaultEngine.ini` 백업 있음).
- **고친 문제**: 파이썬으로 바꾼 메뉴 카메라 위치와 메뉴 레벨 벽등 그림자 설정이 저장되지 않았던 것을 다시 적용해 저장함.
