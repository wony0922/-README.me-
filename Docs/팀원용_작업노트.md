## 2. 실행·테스트하는 법

1. 에디터 툴바의 Play 옆 **⋮** → 플레이어 수 **2**, 넷 모드 **Standalone**으로 설정합니다.
2. Play를 누릅니다. `Lvl_Table`을 열어둔 상태여도 자동으로 메인메뉴로 넘어갑니다(방 없이 테이블 맵에 혼자 들어오면 `BP_GM_Table`이 메인메뉴로 돌려보냄).
3. 창 하나에서 **"방 만들기"**, 다른 창에서 **"방 참가"**를 누르고 방을 고릅니다.
4. 테이블에 앉으면 방장 화면에 "▶ 게임 시작 [SPACE]"가 보입니다. Space를 누르면 게임이 시작됩니다.

### 조작키 (현재 기준)
| 키 | 기능 |
|---|---|
| 마우스 | 고개 돌려 둘러보기 (언제나 가능) |
| A / D | 선택 위치를 왼쪽/오른쪽으로 옮김 (펼친 카드 2장 → 내 마차 2칸) |
| Space | 게임 시작(방장, 시작 전) / 카드 선택 · 마차에 놓기 |
| 마우스 가운데 버튼 (누르고 있기) | 이모트 휠(도넛 모양 4칸). 위로 끌어 놓으면 "가리키기", 오른쪽 "비하하기"(엄지 아래), 아래 "엄지척" |
| E | **임시** 턴 넘기기 |
| W | **임시** 카드 1장 드로우 (테스트용) |
| F9 | **디버그용** 즉시 게임 종료 (골드가 랜덤으로 정해짐) |

> 내 턴이 아닐 때는 둘러보기와 이모트만 할 수 있습니다.
> E, W, F9는 실제 규칙이 들어오면 지우거나 바꿀 예정입니다.

## 3. 지금까지 만든 것

### 3-1. 레벨 (`Lvl_Table`)
- 둥근 테이블 1개, 의자 4개, 플레이어별 마차판 4개(`CardBoard_0~3`), 가운데 덱 1개
- 자리 번호(SeatIndex) 0~3에 따라 플레이어가 앉는 자리가 정해집니다.
- 테이블은 정원(반지름 약 92cm)이고, 의자(±119)와 마차판(±70)이 대칭으로 놓여 있습니다.
- 덱 위에 펼친 카드 2장과 마차 위 카드는 공중에 떠서 각 플레이어 카메라를 바라봅니다.

### 3-2. 게임 흐름
1. **대기**: 방장이 시작할 때까지 기다립니다. 화면 아래에 "접속 인원 n / 4 (최소 2명)"이 표시됩니다.
2. **시작**: 방장이 Space를 누르면 2명 이상일 때만 시작합니다. 모두 **카드 5장**을 받습니다(덱에서 5장 묶음이 날아오는 애니메이션).
3. **턴**: 방장부터 시작해서 접속 순서대로 돌아갑니다. 지금은 E로 넘깁니다.
4. **카드 놓기**: 덱 위에 펼쳐진 카드 2장 중 하나를 고르거나, 손패 맨 왼쪽 카드를 내 마차 칸에 놓습니다. 펼친 카드가 비면 새로 2장이 펼쳐집니다.
5. **마차 정산**(README의 "화로 정산"에 해당):
   - 같은 종류의 카드를 놓으면 개수가 +1이 됩니다.
   - 다른 종류의 카드를 놓으면 기존 카드를 청산합니다. **2장 이상이면 개수 × 가격만큼 골드를 받고**, 1장이면 그냥 버려집니다.
   - 가격(임시값): 돌 1 / 석탄 2 / 금 4 / 철 3 / 다이아 6
6. **게임 종료**: 결과 창에 순위가 나오고, **"한 판 더"**를 누르면 같은 방, 같은 멤버로 다시 시작합니다. 전원이 눌러야 재시작됩니다.

### 3-3. 블루프린트 한눈에 보기 (`Content/MaterialTraders/Blueprints/`)
| 블루프린트 | 역할 |
|---|---|
| `BP_GM_Table` | 게임모드(서버 전용). 게임 시작, 턴 넘기기, 종료, 재시작 |
| `BP_PS_Table` | 플레이어별 점수: 골드, 나무, 재시작 준비 여부 |

| `BP_CardBoard` | 플레이어별 마차판(2칸). 카드 쌓기와 정산 |

### 3-4. 멀티플레이 동기화 방식
- 규칙 판정(카드 놓기, 정산, 골드, 턴)은 **모두 서버에서만** 합니다. 클라이언트는 서버 RPC로 요청만 보냅니다.
- 화면에 보이는 상태(마차 카드, 펼친 카드, 손패 수, 골드)는 Replicated / RepNotify 변수로 모두에게 전달됩니다.
- 머리 방향은 각자 자기 시선을 서버로 보내고, 서버가 다른 사람들에게 복제합니다. 이모트도 같은 경로로 함께 보냅니다. 별도 RPC 없이 시선 회전값의 Roll에 실어 보내고, 가리키기 90, 비하하기 160, 엄지척 -160으로 구분합니다.
- 드로우 애니메이션은 서버가 "몇 번째 드로우인지"(DrawSeq)만 복제하고, 각 컴퓨터가 같은 애니메이션을 직접 재생합니다.

### 3-5. 캐릭터·모델
- 캐릭터는 Blender에서 몸통과 머리를 분리했습니다. 머리가 목을 기준으로 돌아가서 시선 방향이 보입니다.
- 스킨 2종(`Content/Asset/Player1`, `Player2`). Player1 머리에는 볼 홍조가 있습니다.
- 손 모델(`Content/Asset/Hands/`)에는 펴기/쥐기/쉬기/가리키기/엄지척 애니메이션이 있습니다. 지금 쓰는 손 메시는 손날을 평평하게 다듬은 `SK_Hand_R_Flat` / `SK_Hand_L_Flat`입니다(기존 `SK_Hand_R/L`은 안 씀). Blender 원본은 `GameVR.blend`의 `Hand_R` / `Hand_L`입니다.
- 손과 손패 카드는 2배 크기입니다. 테이블 위 덱은 별도로 2배, 마차 카드는 원래 크기입니다.
  - 주의: `CardFan`, `RightHandRoot`, `FlyCard`는 애니메이션이 매 프레임 트랜스폼을 덮어써서 스케일을 바꿔도 소용이 없습니다. 크기를 바꾸려면 그 아래 자식(`LeftHand`, `CardSlots`, `RightHand`, `FlyCardScale`)을 바꾸세요.

## 4. 작업할 때 주의사항 (실제로 겪은 문제들)

- **Play(PIE) 중에 블루프린트를 컴파일하지 마세요.** 에디터가 꺼져서 저장 안 한 작업이 날아간 적이 있습니다. 순서: 정지 → 컴파일 → 저장 → Play.
- **저장이 안 되거나, 지운 액터가 다시 생기면** Git LFS 잠금 설정 때문에 파일이 읽기 전용이 된 것입니다. 프로젝트 폴더에서 명령 프롬프트로 다음을 실행하세요.
  ```
  attrib -r "Content\*" /s
  ```
- **레벨에 이미 놓인 액터는 블루프린트에서 컴포넌트를 추가/변경해도 반영이 안 될 때가 있습니다.** 이때는 액터를 지우고 같은 위치·이름·SeatIndex로 다시 놓으세요.
- 새로 만드는 서버 RPC 이벤트는 디테일 패널에서 **"서버에서 실행" + "신뢰성"**을 꼭 체크하세요. 체크하지 않으면 클라이언트에서 아무 일도 일어나지 않습니다.
- 복제된 회전값(Rotator)은 0~360 범위로 올 수 있습니다. 비교·계산하기 전에 `Delta (Rotator)`로 정규화하세요.
